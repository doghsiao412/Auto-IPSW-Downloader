# Docker 版（Synology NAS）

在 Synology NAS 上用 Docker 執行，把驗證過的韌體複製到外接 USB 硬碟。共同功能見[專案首頁](../README.md)。

## 檔案

| 檔案 | 用途 |
|---|---|
| `Dockerfile`、`compose.yaml` | 容器映像與執行設定 |
| `deploy.sh` | 安裝與更新腳本，在 NAS 上以 sudo 執行 |
| `deploy.env.example` | 站台設定範例（NAS 使用者、管理網址） |
| `exporter.py` | 在 NAS 主機上執行的外接硬碟複製程序 |
| `dsm-mail-report.py` | 交給 DSM 工作排程器寄出通知信 |

## 部署

這是為單一台 Synology NAS 寫的部署方式，不是通用安裝器：假設使用者是 UID 1026 / GID 100（Synology 第一個建立的帳號）、外接硬碟掛在 `/volumeUSB1/usbshare`、安裝到 `/volume1/docker/ipsw-downloader`。環境不同時請先調整 `deploy.sh`、`compose.yaml` 和 `Dockerfile`。
需要 DSM 7、Container Manager、NAS 上的 Python 3.8 以上，以及已開啟的 SSH。容器使用 Python 3.12 與 OpenSSH client，無 Python 第三方套件。
步驟：

1. 把整個專案傳到 NAS 上該使用者的家目錄。
2. 在 `docker/` 裡複製 `deploy.env.example` 為 `deploy.env`，填入 NAS 使用者名稱與管理網址。這個檔案不進版本控制。
3. 接上外接硬碟，執行 `sudo sh docker/deploy.sh`。

腳本不修改 sudoers、sshd 設定或既有 Download Station 任務；僅追加一把有 `from=127.0.0.1,restrict,command=...` 限制的本機金鑰。

目標 Tailscale 為 userspace 模式，因此服務用 host networking 並只監聽 `127.0.0.1:18766`，由 Tailscale 將來自該節點的流量轉入 loopback。Host 檢查只接受 `deploy.env` 設定的 `PUBLIC_HOST`，修改操作另檢查 Origin 與隨機 CSRF token。
沒有額外網頁帳密；可連到此連接埠的 tailnet 成員可以操作，請以既有 Tailscale 存取規則管理。

更新：同步來源後再執行部署腳本，既有設定與資料保留。
停止：`cd /volume1/docker/ipsw-downloader && sudo /usr/local/bin/docker compose down`。
停用與移除容器不刪資料；如要完整移除，先備份設定、紀錄及所需韌體，再移除專用 SSH 授權行、專案與識別檔。

## 使用

部署後以 Tailscale 連線開啟 `http://<NAS 的 Tailscale IP>:18766`。預設暫停。
選類別／指定機型、儲存，按「立即檢查」查看檔案數及容量，再啟用自動下載。
機型留白代表所選類別全部機型，不是零台；所選最新版總容量超過硬碟容量會在下載前停止。

「最新版」沿用網站 `/v4/releases` 的各系統最高正式版本，只下載該版已簽署的 IPSW；不收 beta、OTA 或較舊系統分支。指定機型若不支援目前最高版本，不會退回下載較舊版。
IPSW.me 資料可能延遲，不能保證 Apple 發布時立即偵測。
版本檢查有獨立排程，即使首次同步持續數小時仍會查詢；偵測到新版後，在目前檔案處理結束時重新建立下載佇列。每輪最多同時下載 5 個檔案；版本變更時不再加入舊清單的新任務，既有任務結束後重建清單。

## 介面分頁

介面採用 Liquid Glass 風格的半透明導覽與工具列，依系統偏好呈現淺色或深色；內容區保持較高不透明度。瀏覽器未提供背景模糊時使用實色備用樣式，並尊重減少透明度與動態效果的系統偏好。

- 總覽：服務狀態、儲存空間、目前版本與檢查排程。
- 下載作業：每個檔案的進行中狀態、外接複製／讀回驗證進度及本次清單。
- 設定：裝置範圍、指定機型、檢查頻率與自動清理。
- 通知與紀錄：電子郵件提交狀態、測試通知及下載紀錄。

分頁網址可直接使用 `/#overview`、`/#downloads`、`/#settings`、`/#activity`，支援瀏覽器上一頁／下一頁。切換分頁保留尚未儲存的設定，重新整理頁面仍以已儲存設定為準。

## 多工與進度

最多同時下載 5 個檔案，內部驗證與外接複製各一次處理一個；下載、驗證、複製可交錯進行。下載名額一空出來就遞補下一個檔案；下載完成、等待複製的檔案不佔下載名額，但最多排 10 個，並受內部暫存空間限制，避免下載快於 USB 寫入時不斷累積暫存。已有的續傳暫存保留；每次加入新任務會預留其他任務所需空間，空間不足先完成既有任務再試。

網頁顯示每個檔案的下載／內部驗證進度；外接處理另外顯示複製容量、百分比、平均速度、預估剩餘時間與讀回驗證進度。寫入完成前的磁碟同步以等待狀態顯示，不把複製 100% 當作同步完成。速度與時間依目前階段估算，開始時或磁碟忙碌時可能暫時無法估算。

任何任務失敗會停止加入新任務，保留尚未外接驗證成功的內部檔案；已開始的讀取遇到暫停或硬碟離線後會停止，網路讀取等待仍可能受逾時影響。只在整輪全部外接驗證成功、目前仍啟用且範圍未變時提交完成通知。

## 儲存與清理

- 程式、設定、紀錄及暫存：`/volume1/docker/ipsw-downloader`。
- 韌體先存 `data/staging/*.partial`，支援 HTTP Range 續傳；以大小、API SHA-1 及可用的 SHA-256 驗證後改成 `.ipsw`。
- 最終目錄：指定外接硬碟的 `IPSW-Auto/`，保留 Apple 原始檔名。複製完成並讀回 SHA-256 驗證後，才刪內部暫存。
- 外接硬碟以 `.ipsw-downloader-id` 識別，掛載編號改變仍可尋找；不同硬碟不會被誤用。識別檔不可複製到其他硬碟。
- 不把 USB 掛進容器；透過僅限 NAS loopback、forced command 的專用 SSH 金鑰執行主機複製程序。不使用 DSM 密碼、Download Station 登入或 Docker socket。
- 主機程序確認真實 USB 掛載，並以開啟的檔案系統描述元固定目的地；USB 消失時不會改寫 NAS 掛載點底下的內部磁碟。
- 硬碟未連接時不開始新下載；下載／複製中拔除會保留內部暫存，接回偵測約 30 秒後重試。其他失敗最多約 15 分鐘重試。
- 內部保留 5 GiB、外接保留 2 GiB。外接必須有容納一份新版的餘裕，不會先刪舊版來換空間。
- 開啟自動清理時，只有 `.managed.json` 登記且所有適用機型的新版都已成功同步的舊 IPSW 才能刪除；刪除前確認舊檔雜湊未被更改。其他原有檔案不動。
- 拔除前按網頁外接硬碟卡片上的「安全退出硬碟」，或透過 DSM 退出。同步進行中會拒絕退出，須先關閉自動下載並等目前的複製完成；退出時握有外接硬碟操作鎖，複製、讀回驗證、清理不會同時進行。退出使用 DSM 的 `synousbdisk -umount`，DSM 外接裝置頁面不一定即時更新，退出後可按「重新掛載硬碟」接回，只掛載帶有本工具識別檔的硬碟才會恢復使用。不能保證直接斷電拔除的 exFAT 檔案系統完整性。
- 停用時保留現有暫存；外接檔被手動移走後，下一次啟用檢查會補下載目前最新版。

外接硬碟上自行複製、搬到其他路徑或其他應用程式建立的檔案不會自動清理；本工具不能判斷你是否已將檔案複製到其他電腦。

## 郵件通知

沿用 DSM 已設定的 Gmail，無須在容器保存 Gmail 密碼或安裝通知套件。通知兩種事件：

- 偵測到所選類別的新正式版本或 Build；首次啟用只記錄目前版本，不把現有版本當新版寄出。硬碟未連接仍可通知。
- 目前所選範圍全部 IPSW 已存入外接硬碟、通過驗證且內部韌體暫存已清除。部分下載或複製失敗不會通知完成。

需要先在 DSM「工作排程器」建立一個停用的使用者自訂工作，以部署用的 NAS 使用者執行 `/bin/python3 /volume1/docker/ipsw-downloader/dsm-mail-report.py`，並勾選「傳送執行詳細資訊電子郵件」、取消「僅在異常終止時寄送」。工作保持停用，由程式在事件發生時呼叫 DSM 原生工作排程器執行；收件信箱及 Gmail 登入仍在 DSM 管理。在 `/volume1/docker/ipsw-downloader/dsm-task.json` 寫入 `{"id": 工作編號}`，部署更新會保留此設定。

通知標題與版本、檔案數等資訊放在 DSM 工作報告內文；信件主旨使用 DSM 原生格式。網頁可按「寄送測試通知」。事件及重試紀錄保存在內部磁碟，避免重啟或每 30 分鐘檢查時重複通知同一批版本與檔案；提交失敗會重試，且不阻塞韌體下載。「已提交 DSM」代表工作已執行報告，實際郵件投遞仍由 DSM Gmail 處理。

## 實機驗證

USB 描述元測試須於 Linux 執行。實機驗證分層記錄：容器啟動、經 Tailscale 的 HTTP、SSH 複製及真實外接磁碟小檔讀回。完整 IPSW 下載和人為拔插另行標示，不能以小檔測試視為完成。
